# 时习源代码及数据来源说明

## 源代码

作品源码包含 React 界面、Rust 后端及 Bun 智能体进程。主要入口为 `src/App.tsx`、`src-tauri/src/lib.rs` 和 `sidecar/agent.ts`；依赖及版本见仓库中的锁文件。阅读器排版所用 foliate-js 放在 `src/vendor/foliate-js/`，相关许可文件随源码保留。第三方代码、界面基础组件及许可情况见根目录 `NOTICE`；作品整体采用 AGPL-3.0。

对话链路使用 Claude Agent SDK。该组件不属于开源组件；它的使用与安装包中的再分发条件需由参赛者在正式提交前核对。应用图标的创作来源也需由参赛者补充。

## 数据与示例材料

作品不附带用于训练或微调模型的数据集。运行时数据来自用户自行导入的文件，本机完成格式解析、分块和索引；使用模型功能时，相关文字会发到用户配置的模型接口，范围见设计报告 2.2。

`test-docs/` 下的采购合同、服务协议和示例小说用于演示与测试。正式提交前，参赛者需确认示例文本及应用图标的实际创作来源，并在信息概要表中披露开发时使用的 AI 工具。

## 复现

按仓库 `README.md` 中“跑起来”部分安装 Rust、Node.js、pnpm 和 Bun，再安装依赖并编译 sidecar。全新克隆时须先创建 `src-tauri/binaries/` 目录。前端测试运行 `pnpm test`；Rust 测试在 `src-tauri/` 下运行 `cargo test`。涉及本机回环端口的测试需要允许绑定本机端口。
