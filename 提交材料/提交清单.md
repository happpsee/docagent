## 四、若官方要求演示材料

作品需要用户自行配置模型 API Key（见技术文档 3.1），评委仅安装安装包看不到学习闭环的运行效果。因此**如果**提交要求包含演示材料，建议 3–5 分钟录屏，按这条顺序走：

1. 把 `演示数据/` 里的文件拖进窗口导入
2. 打开采购合同，读到付款条款那一段
3. 等它自动出题 → 用自己的话答**一半对一半不对**
4. 看批改结果：哪条要点没答到、点一下跳回原文那一句
5. 掌握地图 → 记忆看板（看概念怎么按掌握度分档）
6. 打开示例小说，往后翻几页再往回翻，演示防剧透：后面的内容搜不到、也不会主动考
7. 回到首页看今天该复习几个概念

第 3、4 步故意答错是关键——它证明批改是真的对照原文在判，而不是走个过场。

## 六、两个压缩包怎么选

仓库根目录下有两个内容完全相同、仅文件名编码不同的包：

| 压缩包 | 内部文件名 | 何时用 |
|---|---|---|
| `提交包.zip` | 中文（已按 UTF-8 正确标记） | 默认用这个。macOS、以及 Windows 10 及以上自带的解压都能正确还原中文名 |
| `Shixi-submission-ascii.zip` | 全 ASCII | **提交系统解压后中文名变乱码、或上传时报编码错误时，改用这个**。内部路径为 `Shixi-submission/`，不含任何非 ASCII 字符，任何系统都不会出错 |

两者的文件名都不影响评审内容——技术文档正文是中文的。

## 七、两个容易踩的坑

1. **`.md` 是源文件，不要单独提交它。** 里面的图片链接指向仓库的 `docs/screenshots/`，脱离了仓库就打不开图。**要提交的是 `.html`**：5 张效果图已 base64 内嵌，单文件自足，⌘P 可存 PDF，Word 可另存 .docx。若确实需要提交 Markdown，先运行第四节那条命令重新生成 HTML 一并附上。
2. **安装包是快照。** 本目录里的 DMG 是对 `src-tauri/target/release/bundle/dmg/` 的副本。若重新执行了 `pnpm tauri build`，务必用新产物覆盖，否则文档写的版本与提交的安装包不一致。
